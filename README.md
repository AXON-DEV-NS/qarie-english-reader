# 📘 قارئي — تعلّم الإنجليزية من أي ملف ترفعه

موقع ويب كامل (PWA) لقراءة ملفاتك الإنجليزية وتعلّمها: تحديد أي كلمة/جملة/فقرة، شرح بالعربية، نطق مكتوب بالعربية مع التشكيل، صوت تعليمي، قاموس شخصي، بطاقات مراجعة بالتكرار المتباعد، اختبارات، إحصائيات، ومزامنة سحابية اختيارية.

## التشغيل

التطبيق ملفات ثابتة (Static). يكفي تقديمه من أي سيرفر محلي حتى يعمل الـ Service Worker والـ PWA:

```bash
# الخيار الأول (Node)
npx serve .

# الخيار الثاني (Python)
python -m http.server 8080
```

ثم افتح: `http://localhost:8080` — ويمكن تثبيته كتطبيق من زر «تثبيت» في الإعدادات أو من قائمة المتصفح.

> ملاحظة: الفتح المباشر عبر `file://` يعمل جزئياً لكن بدون ميزات PWA/التخزين المؤقت.

## الميزات

- **رفع وعرض**: PDF (بطبقة نص أصلية عبر pdf.js) · Word DOCX (بتنسيقه الأصلي عبر docx-preview) · DOC (نص احتياطي) · TXT · EPUB (epub.js) · صور.
- **OCR**: للصفحات الممسوحة ضوئياً (tesseract.js) — يصبح النص قابلاً للتحديد مع بقاء الشكل الأصلي.
- **التحديد**: نقرة مزدوجة للكلمة، سحب للجملة/الفقرة — بالماوس أو بالإصبع. تظهر نافذة سفلية على الموبايل وبجانب النص على الكمبيوتر.
- **الشرح**: معنى حسب السياق + نوع الكلمة + النطق بالعربية المشكّلة + أمثلة + مرادفات.
- **الصوت**: Web Speech API بلهجة أمريكية/بريطانية، سرعات 0.5x/0.75x/1x، إعادة، ونطق مقطعي.
- **الحفظ**: قاموسي + تلوين الكلمات المحفوظة داخل الملفات + الانتقال إلى موضع الكلمة.
- **المراجعة**: بطاقات Flashcard بتكرار متباعد (سهلة/متوسطة/صعبة) + اختبار اختيار من متعدد + استماع وكتابة.
- **الإحصائيات**: سلسلة الأيام (Streak) + رسم آخر 7 أيام + أفضل الملفات.
- **التصدير**: CSV و Anki، ونسخة احتياطية كاملة (JSON) تصدير/استيراد.
- **مزامنة اختيارية**: Supabase (كلمات + تقدم + ملفات في Storage). بدونها يعمل كل شيء محلياً.
- **PWA**: يعمل بدون إنترنت بعد أول استخدام، مع تخزين الملفات والكلمات في IndexedDB.

## إعداد الذكاء الاصطناعي (اختياري)

من **الإعدادات ← الذكاء الاصطناعي**:

| المزوّد | رابط الخدمة | مثال موديل |
|---|---|---|
| متوافق مع OpenAI (OpenAI / OpenRouter / Groq / Together) | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Google Gemini | يُترك الرابط | `gemini-1.5-flash` |

بدون مفتاح يعمل الموقع بترجمة مجانية (MyMemory) + قاموس إنجليزي (dictionaryapi.dev) + قاموس محلي مدمج لكلمات شائعة، مع نطق عربي تقريبي مولّد تلقائياً.

## إعداد المزامنة (اختياري)

1. أنشئ مشروعاً في [Supabase](https://supabase.com).
2. الإعدادات ← انسخ **SQL** الظاهر تحت «جداول قاعدة البيانات» والصقه في **SQL Editor** ثم Run.
3. من **Project Settings ← API** انسخ `URL` و `anon key` إلى الإعدادات.
4. أنشئ حساباً من نفس الصفحة (إنشاء حساب) وسجّل الدخول — تتم المزامنة تلقائياً.

## اختصارات الكيبورد

`Space` استماع · `S` حفظ · `Esc` إغلاق · `←/→` تنقل بين الصفحات · `+/-` تكبير/تصغير · `F` قلب البطاقة · `1/2/3` تقييم البطاقة.
